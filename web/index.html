Interakt

A Java console sandbox: you create worlds and actors, let time pass, and watch the actors move, meet, befriend each other and have children. The original program runs unchanged in your browser, in its console mode.

Type a command and press Enter (or tap a shortcut below). A good first session:

  • help lists every command.
  • generatetestdata creates a world called Test with 25 actors in it.
  • elapse makes time pass once; time also passes on its own once a minute.
  • list shows the actors and worlds, view <name> one of them, relations <actor> its friendships, stats the totals.
  • create actor <name>, create world <name> and place <actor> <world> build your own.

Your data is saved in this browser (it is also saved every few minutes and by save), so it is still there after a reload. wipe deletes it.

Loading Java (the first visit downloads the runtime, which can take a little while)...

Runs in your browser with CheerpJ (Leaning Technologies).
